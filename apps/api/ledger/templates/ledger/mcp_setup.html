Verify without changing any records

  1. Configured: the current client lists the correct endpoint.
  2. Authenticated: browser OAuth succeeded or the existing credentials are valid.
  3. Verified: the current conversation can call get_account_context with {} and confirm the returned account identity and MeroSplit links.

No group or transaction lookup is needed. Do not create bills, contacts, payments or other fixtures to verify setup. Configuration saved and OAuth succeeded are intermediate states, not a verified connection.

Other Streamable HTTP clients

Use the exact endpoint above with built-in browser OAuth. The server advertises protected-resource and authorization-server discovery, automatic public-client registration and PKCE S256. Keep the registered redirect URI exact, retain state, and send the discovered resource in authorization and token requests. Do not enter a manual key or copy browser cookies.

If setup stops

  • Sign-in or access expired: use the client's built-in OAuth login, then review the displayed MeroSplit account. Do not create another server entry.
  • CSRF verification failed: restart the connection from your client in the same browser with cookies enabled. Do not disable CSRF or paste tokens.
  • Invalid tool arguments: follow the advertised input schema. get_account_context takes {}. To read requested groups, list_groups accepts {"limit":1}; use a returned UUID for get_group, not a group name.
  • Conflict: review the current record with the user. Do not replace command IDs or silently retry changed financial records.

Record changes safely

Use integer paise strings in INR, for example "12345" for ₹123.45. Keep the same entity ID, command UUID and payload when retrying a lost reply. A bill edit or reversal needs its exact bill version. Reversal creates a separate linked history record and keeps the original. Saved financial records cannot be deleted or restored. A conflict requires review, not a silent refreshed retry. A manual external payment requires a date or explicit null for unknown date, and omits both attempt_id and expected_group_version. It records money already transferred elsewhere.

Disconnect

Open MeroSplit, then Me → Connect MCP → Disconnect beside the connected agent. This revokes both its access and refresh credentials. A request already running can finish. Account deactivation and deletion also stop access. These instructions do not claim public directory approval or that a host installation has been performed.
